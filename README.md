# iPod 5.5th Generation – AirFly Pro Bluetooth Modification

Hardware, firmware, schematics, and development documentation for integrating an AirFly Pro Bluetooth transmitter into an Apple iPod 5.5th Generation.

## Project Overview

This project explores integrating the AirFly Pro Bluetooth audio transmitter into an iPod 5.5th Generation, creating a compact, internally installed Bluetooth audio solution.

The modification focuses on hardware integration, custom microcontroller-based control, and maintaining the original iPod's functionality.

## Development Goals

- Integrate the AirFly Pro Bluetooth transmitter inside the iPod.
- Develop custom firmware for Bluetooth power and pairing control.
- Implement physical button control using the original iPod Hold Switch assembly.
- Minimize component size and internal space requirements.
- Optimize power consumption using the iPod's internal battery.
- Maintain compatibility with the iPod's existing hardware and Rockbox.

## Hardware

Microcontroller selection is currently under evaluation.

The project will document:
- Microcontroller options and specifications.
- AirFly Pro circuit modifications.
- Button and transistor control circuitry.
- Power distribution and electrical connections.
- Wiring diagrams and schematics.

## Firmware

Firmware development will focus on:
- Button input detection.
- Short-press and multi-tap recognition.
- Bluetooth pairing and reset control.
- Power management.
- Reliable operation with minimal hardware overhead.

## Repository Structure

- `firmware/` – Microcontroller source code.
- `documentation/` – Hardware documentation and development notes.
- `schematics/` – Circuit diagrams and wiring references.

## Project Status

**Development in progress.**

Hardware integration, microcontroller selection, firmware development, and testing are ongoing.
